# Lino Livre — Livros Livres, Para Todos

Plataforma aberta, ultrassimples e direta para distribuição, leitura online e download de livros digitais e clássicos da literatura.

O projeto utiliza **capas originais históricas reais** digitalizadas de primeiras edições em domínio público (fontes: *Wikimedia Commons*, *Biblioteca Brasiliana Guita e José Mindlin*, *Wikisource*), armazenadas localmente para velocidade e disponibilidade total.

---

## ✨ Características Principais

- 📚 **Capas Originais Históricas Reais**: Cada obra exibe a fotografia/digitalização de sua capa original histórica de publicação (Machado de Assis 1881 e 1899, Aluísio Azevedo 1890, Lima Barreto 1915, Castro Alves 1870, José de Alencar 1857 e 1865).
- 📖 **Leitura Online Imediata**: Leitor integrado com tipografia clássica e ajuste de tamanho de fonte no próprio navegador.
- ⬇️ **Download Direto**: Baixe as obras em formatos abertos com um único clique.
- ⚡ **Simplicidade Máxima**: Sem burocracias, sem contas obrigatórias, sem controle de estoque físico ou devoluções — apenas livros livres.

---

## 🚀 Como Iniciar

```bash
# 1. Instalar dependências (apenas express)
npm install

# 2. Popular o acervo com as capas originais
npm run seed

# 3. Iniciar o servidor
npm start
```

Abra o navegador em: **[http://localhost:3000](http://localhost:3000)**
